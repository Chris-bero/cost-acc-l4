Key Concepts Review

Absorption vs Variable Costing

Absorption (Traditional): Includes ALL manufacturing costs (DM + DL + V.MOH + F.MOH) in product cost. Fixed MOH is inventoriable.
Variable (Contribution): Includes ONLY variable manufacturing costs (DM + DL + V.MOH) in product cost. Fixed MOH is treated as period expense.

Income Statement Formats

Absorption: Sales - COGS = Gross Margin - S&A Expenses = Operating Income
Variable: Sales - Variable Costs = Contribution Margin - Fixed Costs = Operating Income

Inventoriable Costs

Absorption: DM + DL + V.MOH + F.MOH
Variable: DM + DL + V.MOH only

Key Formulas

Absorption Unit Cost = DM + DL + V.MOH + (F.MOH / Units Produced)
Variable Unit Cost = DM + DL + V.MOH
COGS = Units Sold × Unit Cost
Gross Margin = Sales - COGS
Contribution Margin = Sales - Total Variable Costs

Inventory Impact

When Production > Sales: Absorption Income > Variable Income (some fixed MOH deferred in inventory)

When Production < Sales: Absorption Income < Variable Income (fixed MOH released from inventory)
